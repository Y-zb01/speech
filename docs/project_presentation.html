🎯 项目概述

本项目面向语音算法实习生岗位，完整实现从原始音频数据处理 → Mel 特征提取 → VAD 语音活动检测 → TTS 文本转语音推理 → MOS 主观听音评测的端到端流程。 采用 Mac（开发/评测主控）+ Windows WSL2（GPU 训练/批量推理）双机协同架构， 通过 Git / GitHub 完成跨平台协作与代码同步。

🔧 关键挑战与解决方案

问题
VAD 能量阈值一刀切 — 用户自录短句被切成 230 个碎片，最碎的仅 0.01s
解决
改用 LibriSpeech 标准数据集作为模块一输入，保证数据质量。VAD 仅用于演示长音频切分能力（160s → 50 段，1~4.5s 合理范围）。 使用中值滤波 + 段合并 + 时长过滤三层后处理保证切分质量。
问题
Gradio 6.x 不兼容 — 提交评测后页面报错，gr.update() API 已废弃
解决
移除所有 gr.update() 调用，改为直接返回值。将评分滑块加入 outputs 列表，提交后自动重置为默认值。
问题
双机 Git 同步冲突 — Windows 端产出覆盖 Mac 端版本，pull 时产生合并冲突
解决
统一以 GitHub 为 single source of truth。数据产出通过 .gitignore 精确控制哪些目录纳入版本管理（segments/denoised/wavs 通过 !outputs/**/*.wav 放行）。
问题
macOS Matplotlib 中文显示为方块 — 默认字体不含 CJK 字形
解决
在所有画图脚本中设置 matplotlib.rcParams["font.sans-serif"] = ["PingFang SC", "Heiti SC"]。
问题
GitHub 443 端口直连超时 — 国内网络环境需要代理
解决
检测本地 Clash Verge 代理端口（7897），配置 git config http.proxy 和 https.proxy，Token 嵌入 remote URL 实现免密推送。

⚙️ 核心技术参数

🎵 音频预处理

  • 采样率：24000 Hz · 单声道 · PCM16
  • 输入：LibriSpeech dev-clean · 10 条 flac
  • 时长范围：4.49s ~ 8.42s
  • 4 位独立说话人

📊 Mel 特征

  • n_fft=1024 · hop_length=256
  • n_mels=80 · fmax=12000Hz
  • 输出格式：.npy (n_mels, frames)
  • 每张频谱可独立用于模型训练

🎙️ VAD 检测

  • 帧长 25ms · 帧移 12.5ms
  • 自适应能量阈值 + 中值滤波(窗口3)
  • 段合并间隔 < 0.3s
  • 输入：160s 长音频 → 输出：50 段（1.0~4.6s）

🤖 TTS 推理

  • 引擎：Microsoft Edge-TTS
  • 音色：XiaoxiaoNeural（女）+ YunxiNeural（男）
  • 10 句中文测试文本 × 2 音色 = 20 条
  • 3 次重试机制 · 0.5s 间隔防限流

📝 MOS 评测

  • 双维度：自然度 + 音色相似度（1~5，0.5步进）
  • 8 类 Bad Case 标签
  • Gradio 6.x · 支持局域网访问
  • CSV 持久化 · 断点续评

🖥️ 双机协同

  • Mac ARM64：开发 + 小样本 + 评测
  • Windows WSL2 Ubuntu：GPU 训练 + 批量推理
  • Git + GitHub 代码同步
  • YAML 配置驱动 · 零硬编码路径
